# Контент-фабрика «Макс Движ» — коротко для Димы

1. Скачай файлы из этой папки в `C:\Users\Hello Dmitry\ai\neuroblog\factory\`. Рядом, в `neuroblog\`, уже лежат `persona.md` и `scenarios-30.md`. Python 3 у тебя стоит, ничего доустанавливать не нужно.
2. Скопируй `config.example.json` в `config.json` и впиши свои ключи: `llmmart_key` (LLM Mart → Ключи; нужен ключ для вызова моделей, ключ кабинета не подойдёт) и `vk_group_token` (токен группы, шаг 3). Файл `config.json` никому не отправляй.
3. Токен группы: группа → Управление → Работа с API → Ключи доступа → Создать ключ. Отметь права «Стена», «Фотографии», «Сообщения» и подтверди кодом. Ещё в разделе «Сообщения» включи сообщения сообщества.
4. Запусти один раз `install_tasks.bat` двойным щелчком, права администратора не нужны. Он создаст три задачи: в понедельник в 09:00 — 7 постов на неделю в отложенные ВК, каждый день в 08:00 — картинка дня, каждые 10 минут — автоответ на «ТЕЛО».
5. Пост в ВК: текст с призывом «Напиши ТЕЛО в сообщения группы», без ссылки. Ссылку с кодом DVIZH (скидка 10%) получает в личку тот, кто написал ТЕЛО (`reply_telo.py`, текст ответа — `telo_reply.txt`).
6. Перед публикацией тексты можно поправить в `posts\dayN.txt`. Картинки сохраняются в `images\dayN.png`. Токен группы не умеет прикреплять фото к постам, поэтому картинки ставь вручную или через агента.
7. Ручные команды (в папке factory): `python write_week.py`, `python vk_autopost.py --dry-run` (только показать, ничего не отправляет), `python vk_autopost.py`, `python gen_image.py --day 8`, `python gen_video.py --day 8`, `python reply_telo.py --dry-run`.
8. Цены (замер 20.11.2026, LLM Mart): картинка FLUX 3 Klein — 1,25 ₽. Клип 5 с Grok Imagine Video 1.5 Lite (720p, вертикальный) — около 16 ₽ по каталогу, итог после теста — в отчёте Атласа. 7 постов на Kimi K3.1 Pro — несколько рублей. Все траты пишутся в `logs\spend.csv`.
9. Журналы: `logs\run_weekly.log`, `logs\daily_image.log`, `logs\telo.log`. Если компьютер был выключен, запусти `run_weekly.bat` вручную. Автоответ сам догонит всех, кто написал, пока ПК был выключен.
10. Если что-то сломалось, пришли Максиму последние строки нужного файла из `logs\`.
